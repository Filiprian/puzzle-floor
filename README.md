# Puzzle floor
Small 3D puzzle game with Unity
You can play it in your browser right here: https://filiprian.itch.io/puzzle-floor  

## Main features:
- Rotating platform to get a blue ball into a goal (green zone)
- Blue and the goal cannot touch red color
- Gray ball is your friend, who can open you doors

## Controls:
- **WSAD/arrows** - Rotating platform
- **R** - Switch camera angle
- **X** - Emergency respawn
- **Esc** - Pause the game

## Key game logic:
- Collisions of objects
